# JSON Tree Viewer

- Java 17 target for IC-232 runtime compatibility
- IntelliJ Platform 2023.2+
- Right-side tool window with JSON tree
- Toolbar: Collapse All, Expand All, Refresh
- Bottom search with Up/Down directional search
- Icons for object/array/value nodes, bold key part in labels
- Disables controls with message if active editor is not JSON
- Refresh on focus with selection restore

Build:
```
./gradlew build
```

Run:
```
./gradlew runIde
```
